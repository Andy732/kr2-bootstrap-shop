# Контрольная работа №2 — «Дом рядом»

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Отдельная учебная реализация интернет-магазина товаров для дома и отдыха. Главная страница использует Bootstrap-сетку и собственные стили.

## Используемые технологии

- HTML5;
- Bootstrap 5.3.8 через CDN;
- CSS;
- Git и GitHub.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── css/
│   └── custom.css
├── images/
├── .gitignore
└── README.md
```

## Что реализовано

- hero-блок с переходом к товарам;
- адаптивная Bootstrap-навигация с раскрывающимся мобильным меню;
- блок преимуществ;
- сетка популярных товаров;
- адаптивные колонки `col-12`, `col-md-*`, `col-lg-*`;
- отступы между колонками через `g-*`;
- собственный файл `custom.css`, подключённый после Bootstrap.
- Bootstrap JS Bundle для мобильной навигации, выпадающего меню, модальных окон и accordion;
- каталог на компонентах `card`, кнопках `btn`, значках `badge` и сообщениях `alert`;
- страницу товара с Bootstrap-таблицей и блоком частых вопросов `accordion`;
- страницу заявки с `form-control`, `form-select`, `input-group` и `form-check`.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Добавлены общая адаптивная навигация, каталог, страница товара, демонстрационная форма заявки и Bootstrap-компоненты. Формы не подключены к серверу и не отправляют данные.

## Проверка

Откройте `index.html` в браузере при подключённом интернете. Проверьте меню, каталог, страницу товара, форму, модальное окно и accordion. Для проверки адаптивности используйте ширины 375, 768, 1024 и 1440 px.
